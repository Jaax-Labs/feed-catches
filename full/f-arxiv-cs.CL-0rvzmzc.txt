Computer Science > Artificial Intelligence arXiv:2610.18497v1 (cs) [Submitted on 13 Oct 2026] Title: Judges Follow the Reference: The Derivation Gap in Verifying Tool-Call Arguments Authors: Linhai Ma , Yan Wang , Lingfei Qian , Yupeng Cao , Victor Gutierrez Basulto View a PDF of the paper titled Judges Follow the Reference: The Derivation Gap in Verifying Tool-Call Arguments, by Linhai Ma and 4 other authors View PDF HTML (experimental) Abstract: Tool-call judges evaluate argument values proposed by LLM agents. We find that they accept a correct value less often when their input holds no reference for it, that is, no text that says what the value should be. This happens when the value is a default value from the function schema that the user did not mention, when it has to be inferred, or when the text it comes from was cut from the judge input. We call this drop in acceptance the derivation gap. It appears across all seven judges we evaluate, including System One models CLM and Jev. The gap is not only a truncation artifact: correct default values have the largest gap on a benchmark with no truncation. A controlled source-relocation test shows that judges follow the reference in their input: they favor a visible incorrect value over a correct value whose source is hidden. We introduce DeRef (Derived Reference): a separate model reads the full history without seeing the candidate and writes a reference for the judge. Across three benchmarks, DeRef improves overall argument AUROC for all judges tested. On the controlled test, it raises AUROC from chance or below to between 98.40 and 99.59.
